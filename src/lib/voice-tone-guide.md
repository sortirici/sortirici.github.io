# Voice & Tone Guide — SortirIci

> **Archétype : Guide Bienveillant**
> Le ton de SortirIci est celui d'un ami qui connaît sa ville — chaleureux, précis, jamais commercial.

---

## 1. Personnalité de la marque

### Qui est SortirIci ?

SortirIci est **le guide de confiance** qui connaît chaque recoin du territoire. Pas un moteur de recherche froid, pas un site commercial qui pousse des ventes — un compagnon utile qui dit : **"Voilà ce qui se passe près de chez toi, et tu peux y aller les yeux fermés."**

| Si SortirIci était une personne... | |
|------------------------------------|---|
| **Son métier** | Bibliothécaire ou guide touristique local — passionné par sa région, jamais condescendant |
| **Son âge** | 35-45 ans — assez jeune pour connaître les applis, assez mûr pour être fiable |
| **Son caractère** | Calme, précis, enthousiaste sans être envahissant |
| **Son défaut** | Parfois un peu trop sérieux sur la fiabilité des sources |
| **Sa phrase** | "Vas-y, c'est une bonne sortie — je me suis renseigné." |

### Les 5 valeurs incarnées dans le ton

| Valeur | Traduction dans le ton |
|--------|----------------------|
| **Confiance** | On cite nos sources, on explique d'où viennent les données. Transparence totale. |
| **Utilité** | Priorité à l'information pratique : date, lieu, prix, accès. Pas de blabla. |
| **Respect** | Pas de tracking, pas de recommandations forcées. L'utilisateur décide. |
| **Simplicité** | Phrases courtes, mots simples. On explique pas ce qui est évident. |
| **Ancrage local** | On parle des villes, des départements, des régions avec précision. On connaît le territoire. |

## 2. Principes d'écriture (Voice Principles)

### 2.1. Précis, pas vague

| ❌ À éviter | ✅ À privilégier |
|------------|-----------------|
| "De nombreux événements sont disponibles" | "45 événements référencés dans le Loiret" |
| "Bientôt" | "Du 15 au 18 mars 2025" |
| "Un lieu sympa" | "Salle des fêtes de Saran, rue de la Gare" |
| "Plein de choses à faire" | "Concerts, expositions et ateliers ce week-end à Orléans" |

### 2.2. Utile, pas commercial

| ❌ Commercial / Push | ✅ Utile / Guide |
|--------------------|-----------------|
| "Ne ratez pas cette offre exceptionnelle !" | "Cet événement est programmé le 15 mars" |
| "Cliquez vite pour réserver !" | "Retrouvez toutes les infos sur la fiche source" |
| "Découvrez nos suggestions exclusives" | "3 événements similaires dans la même catégorie" |
| "Inscrivez-vous à notre newsletter" | (Pas de newsletter — 0 email, 0 tracking) |

### 2.3. Chaleureux, pas familier

| ❌ Trop froid (administratif) | ❌ Trop familier (décontracté) | ✅ Juste bien (chaleureux) |
|------------------------------|------------------------------|--------------------------|
| "L'utilisateur est informé que..." | "Yo ! Check les events du coin !" | "Voici les événements près de chez vous" |
| "Les données sont issues de..." | "On a piqué les infos sur..." | "Les données de cet événement viennent de..." |
| "Aucune correspondance trouvée" | "Oups, rien trouvé :(" | "Aucun événement pour ce filtre. Essayez une autre catégorie ?" |

### 2.4. Local, pas générique

| ❌ Générique | ✅ Local |
|-------------|---------|
| "Découvrez les événements" | "Que se passe-t-il dans le Loiret ce week-end ?" |
| "Trouvez des activités" | "Sortir à Orléans et dans le 45" |
| "Les sources" | "Les données de votre département viennent de..." |

### 2.5. Rassurant, pas alarmiste

| ❌ Anxiogène | ✅ Rassurant |
|-------------|-------------|
| "Attention : vérifiez les dates !" | "Vérifié le 15 mars — source OpenAgenda" |
| "Les données peuvent être erronées" | "Informations fournies par {source}, sous licence {licence}" |
| "Aucun résultat" | "Il n'y a pas encore d'événements référencés dans ce département. Revenez bientôt !" |

## 3. Guide par canal / contexte

### 3.1. Page d'accueil

**Ton** : Accueillant, clair, confiant. C'est la première impression.

| Élément | Texte proposé | Pourquoi |
|---------|--------------|----------|
| Titre H1 | "Sortir près de chez vous, en confiance" | "En confiance" = valeur clé, rassure immédiatement |
| Sous-titre | "100% open data, 0 cookie, 0 tracking. Les événements près de chez vous, sourcés et vérifiés." | Transparence radicale = confiance |
| Placeholder recherche | "Rechercher un événement, une ville, un département..." | Large, inclusif, pas restrictif |
| CTA secondaire | "Explorer par département" | Action claire, pas de "Découvrir" vague |
| Stats | "12 000 événements · 15 sources · 45 départements" | Chiffres précis, pas arrondis |

### 3.2. Hub Département

**Ton** : Précis, utile, local. L'utilisateur cherche des informations pratiques.

| Élément | Texte proposé | Pourquoi |
|---------|--------------|----------|
| Titre H1 | "Loiret (45) — 230 événements référencés" | Précis, chiffré, immédiat |
| Filtre date "Toutes les dates" | "Toutes les dates" | Pas de "Toujours" bizarre |
| Aucun résultat | "Aucun événement avec ces filtres. Essayez de modifier votre recherche." | Guide, pas blâme |
| Source | "Données fournies par OpenAgenda" | Transparence, pas de "Partenaires" |
| Pagination | "Page 2 sur 5" | Neutre, fonctionnel |

### 3.3. Fiche Événement

**Ton** : Détail, confiance, exhaustif. L'utilisateur a besoin de toutes les infos.

| Élément | Texte proposé | Pourquoi |
|---------|--------------|----------|
| Titre H1 | Le titre de l'événement (donnée source) | Pas de réécriture, on respecte la source |
| Source | "Les données de cet événement proviennent de {sourceName} sous licence {licence}." | Transparence totale |
| Lien source | "Voir la fiche source originale" | Pas de "En savoir plus" vague |
| Gratuit | "Gratuit" (badge vert) | Simple, visible |
| Événements similaires | "Vous aimerez aussi" | Chaleureux, pas "Recommandations" |

### 3.4. États d'erreur / vides

**Ton** : Désolé mais utile, jamais frustré.

| Contexte | Texte proposé |
|----------|--------------|
| Aucun événement | "Il n'y a pas encore d'événements référencés dans ce département. Revenez bientôt — nous ajoutons régulièrement de nouvelles sources." |
| Aucun résultat filtre | "Aucun événement ne correspond à ces filtres. Essayez de modifier votre sélection ou d'élargir la période." |
| Erreur chargement | "Les données n'ont pas pu être chargées. Le site est statique, réessayez dans un instant." |
| 404 | "Page non trouvée. Retournez à l'accueil pour explorer les événements près de chez vous." |

### 3.5. Mentions légales / Sources

**Ton** : Transparent, humble, précis.

| Élément | Texte proposé |
|---------|--------------|
| Titre | "Nos sources — 100% open data, 0 cookie" |
| Intro | "SortirIci ne collecte aucune donnée personnelle. Tous les événements proviennent de sources publiques, dont voici la liste." |
| Licence | "Licence Ouverte (Etalab) — Permet la réutilisation libre des données" |

## 4. Lexique — Mots à utiliser / éviter

### Mots à utiliser ✅

| Mot | Pourquoi |
|-----|----------|
| **Événement** | Neutre, universel |
| **Sortir** | Actif, positif |
| **Près de chez vous** | Local, chaleureux |
| **Référencé** | Précis, fiable |
| **Source** | Transparence |
| **Confiance** | Valeur clé |
| **Gratuit** | Utile, attendu |
| **Programmé** | Précis |
| **Vérifié** | Sûr |
| **Département** | Ancre géographique |
| **Open data** | Transparence, éthique |

### Mots à éviter ❌

| Mot | Pourquoi l'éviter |
|-----|-------------------|
| **Offre** | Trop commercial |
| **Promo / Promotion** | Trop commercial |
| **Exclusif** | Marketing, pas crédible |
| **Inscrivez-vous** | Pas de login |
| **Newsletter** | Pas d'email |
| **Abonnez-vous** | Pas de modèle abonnement |
| **Recommandé** | Subjectif, on ne recommande pas |
| **Viral / Tendance** | Pas de jeu social |
| **Meilleur** | Subjectif |
| **Gratuit** (trop utilisé) | Utiliser sur les vrais gratuits seulement |
| **Like / Partager** | Pas de boutons sociaux |

## 6. Anti-patterns — Ce qu'on ne fait JAMAIS

1. **❌ Utiliser des superlatifs creux** (« meilleur », « incroyable », « unique »)
2. **❌ Faire du push commercial** (« Réservez vite », « Offre limitée », « Ne ratez pas »)
3. **❌ Utiliser du jargon technique** (« UX », « onboarding », « frictionless »)
4. **❌ Être condescendant** (« Comme vous le savez sûrement », « Évidemment »)
5. **❌ Tutoyer ou vouvoyer de façon incohérente** → On tutoie (comme un guide bienveillant)
6. **❌ Utiliser des anglicismes inutiles** (« events », « meeting », « workshop », « newsletter »)
7. **❌ Faire de l'humour forcé** (« Votre week-end va être chargé ! », « Préparez-vous à sortir ! »)
8. **❌ Utiliser le nom de l'utilisateur ou des données personnelles** (on n'en a pas)
9. **❌ Mettre des émoticônes ou des interjections** (« 😊 », « Ouais ! », « Trop bien ! »)
10. **❌ Faire des promesses non tenues** (« Nouveaux événements chaque jour » si on ne peut pas garantir)

## 7. Checklist qualité avant publication

Pour chaque texte, se poser ces 3 questions :

1. **Est-ce utile ?** — L'utilisateur a-t-il besoin de savoir ça ?
2. **Est-ce précis ?** — Les dates, chiffres et noms sont-ils exacts ?
3. **Est-ce digne de confiance ?** — La source est-elle citée ? Les limites sont-elles claires ?

Si la réponse à l'une des trois est non, **réécrire**.
